Nix system setup plan

Shared plan for rebuilding Max’s Mac setup with Nix, nix-darwin, Determinate Nix, nix-homebrew, and Home Manager.

This is a plan only. Do not implement until explicitly asked.

Overall direction

  • Rewrite the failed scaffold and start fresh.
  • Use a notthebee-inspired layout with machines under modules/machines.
  • Use flake-parts for top-level flake structure.
  • Initialize a fresh local Git repo after implementation; no remote yet.

Flake inputs

  • nixpkgs: github:NixOS/nixpkgs/nixpkgs-unstable.
  • home-manager: rolling GitHub input, follows nixpkgs.
  • nix-darwin: rolling GitHub input, follows nixpkgs.
  • determinate: recommended FlakeHub URL, independent from local nixpkgs.
  • nix-homebrew: minimal standard input.
  • treefmt-nix: for nix fmt and formatting check.
  • No nixpkgs-stable for now.

Machine discovery

  • Darwin configs are auto-discovered from modules/machines/darwin/*/configuration.nix.
  • NixOS auto-discovery framework is included for future servers, initially empty.
  • Primary host is fawkes, aarch64-darwin.

Darwin and Nix

  • Use Determinate Nix compatibility module for nix-darwin.
  • Configure Darwin Nix settings through determinateNix.customSettings, not nix.settings.
  • Trusted users: root and mkn.
  • Enable flakes and nix-command.
  • Use max-jobs = auto, cores = 0, keep-outputs = true, keep-derivations = true.
  • Use Determinate automatic GC via determinateNixd.garbageCollector.strategy = "automatic".

Homebrew

  • Install/manage Homebrew through nix-homebrew.
  • User: mkn; prefix: /opt/homebrew; no Rosetta.
  • Conservative cleanup: cleanup = "none".
  • Enable Homebrew auto-update and upgrade on activation.
  • No custom taps and no global no-quarantine setting.

Formatting and validation

  • Use Alejandra as the repo formatter through treefmt-nix.
  • nix fmt formats the repo.
  • nix flake check stays lightweight, mainly formatting/buildability.
  • No dev shell, CI, deadnix, statix, or nix-index initially.

Just commands

fmt:      nix fmt
check:    nix flake check
build:    nix build .#darwinConfigurations.fawkes.system --no-link
switch:   sudo -H darwin-rebuild switch --flake .#fawkes
doctor:   just fmt; just check; just build

Dotfiles

  • Use mutable Home Manager out-of-store symlinks.
  • Repo path is hardcoded as /Users/mkn/nix-config.
  • Explicit symlink declarations only; no auto-linking whole trees.
  • Initially symlink only Pi and Zed dotfiles.

Pi

  • Do not install or update Pi through Nix.
  • Set PI_CODING_AGENT_DIR=$XDG_CONFIG_HOME/pi/agent.
  • Set PI_TELEMETRY=0; do not skip version checks.
  • Manage minimal repo-backed files: AGENTS.md, settings.json, keybindings.json, prompts/, skills/, themes/, extensions/.
  • Do not track sessions, package installs, auth, or runtime state.

Zed

  • Install Zed via Homebrew.
  • Seed settings.json and keymap.json from ~/nix-old/users/mkn/dotfiles/zed/.
  • Do not include tasks.json.
  • Remove all Zed agent-related settings.
  • Keep non-agent preferences like theme, layout, telemetry disabled, terminal, and language settings.
  • Use Alejandra as external Nix formatter.
  • Use nixd explicitly as Nix LSP.
  • Symlink individual files only, not the whole Zed config directory.

Not included initially

  • SSH config and keys.
  • Secrets tooling such as agenix or sops-nix.
  • Fonts.
  • Login items / auto-start management.
  • App preference management for GUI apps other than the noted Ghostty/Zed exceptions.
  • Node/npm, since Node is managed via Vite Plus.

Repo docs
