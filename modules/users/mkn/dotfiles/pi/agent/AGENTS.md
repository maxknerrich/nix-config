# Pi agent notes

- Follow the repository `AGENTS.md` first.
- Do not store secrets, auth tokens, sessions, or runtime state here.
- Ask questions one at a time.

## TypeScript

- Add packages with the package manager instead of editing `package.json` manually.
- Run the available check, format, and lint commands after changes. If they do not exist, suggest adding them.
- Avoid explicit return types unless needed.
- Use real type safety and inference; treat `as any` as a last resort.

## Svelte

- Load the Svelte skills whenever writing, editing, or analyzing Svelte components or modules.
